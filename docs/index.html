This page previews the lodging finder. To place it on a trlibrary.com page, paste this into a code block:

<div id="trpl-lodging"></div>
<script src="https://lodging.labs.trlibrary.com/lodging.js" defer></script>

Add data-heading="off" to the script tag when the page already has its own heading. The availability monitor shows every tracked night in one grid.
